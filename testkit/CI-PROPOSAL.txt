1. build.yml, job "test": show the report and keep the pictures
--------------------------------------------------------------
Add after the `flutter test` step (same pinned action as launch-test.yml):

      - name: Probe Test Kit report
        if: always()
        run: |
          if [ -f testkit-out/latest/report.md ]; then
            cat testkit-out/latest/report.md >> "$GITHUB_STEP_SUMMARY"
          else
            echo "No Probe Test Kit report was written." >> "$GITHUB_STEP_SUMMARY"
          fi
      - name: Upload Probe Test Kit output
        if: always()
        uses: actions/upload-artifact@cf430e030ddbb5b0abf93d22962f4752f3646cd9 # v7.0.2
        with:
          name: testkit-out
          path: testkit-out/latest/
          if-no-files-found: ignore
          retention-days: 14

Permissions stay `contents: read`. No secret is used. The pictures show the
game with invented data only.

2. repo-rules.yml: the manifest ratchet (acceptance A5)
------------------------------------------------------
Add a step in job "check" after "Check commits", on pull_request only. The PR
body is passed through an environment variable, never inlined in the script
(SEC-13). The base branch's manifest is read with `git show`.

      - name: Probe Test Kit manifest ratchet
        if: github.event_name == 'pull_request'
        env:
          PR_BASE: ${{ github.event.pull_request.base.sha }}
          PR_BODY: ${{ github.event.pull_request.body }}
        run: |
          set -euo pipefail
          if ! git cat-file -e "$PR_BASE:testkit/manifest.json" 2>/dev/null; then
            echo "No manifest on the base branch yet: nothing to compare."
            exit 0
          fi
          git show "$PR_BASE:testkit/manifest.json" > "$RUNNER_TEMP/base-manifest.json"
          reason=$(printf '%s\n' "$PR_BODY" | sed -n 's/^TESTKIT-CHANGE:[[:space:]]*//p' | head -1)
          # needs the Dart SDK: either add subosito/flutter-action to this job
          # (pinned like build.yml) or run `dart` from the Flutter install.
          dart run testkit/tool/check_manifest.dart \
            --base "$RUNNER_TEMP/base-manifest.json" \
            --head testkit/manifest.json \
            --reason "$reason"

Cheaper alternative with no Dart: keep this step in build.yml's "test" job,
which already has Flutter, and run it after `flutter pub get`.
